我們的理念是為訂閱者打造最好的產品體驗，同時把 Life Note、日記書寫以及 AI 導師的種種好處，分享給越多人越好。

Life Note 完全靠訂閱支持成長。我們永遠不會販賣你的資料。

## 兩種方案

|  | 免費 | 訂閱 |
| --- | --- | --- |
| 日記 | 每週 3 篇 | 無限制 |
| 導師回覆 | 每篇日記 1 位導師 | 每篇日記最多 3 位導師 |
| 深度對話 | 使用量有限 | 更多使用量，對話更深入 |
| 記憶品質 | 中 | 高 |
| 語音書寫 | 每週 10 段錄音 | 每月 200 段 |
| 日記中的照片 | 標準解析度 | 完整解析度 |
| 掃描日記 | 每週有上限 | 上限較高 |
| 人生目標 | 基礎的導師引導 | 更深入的導師整合 |

<Tip>
  **你的第一週更寬鬆。** 新帳號在最初七天內可以寫 10 篇日記，而非 3 篇 — 讓你在週節奏穩定下來之前，先找到自己的步調。
</Tip>
