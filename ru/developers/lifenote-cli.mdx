В дневнике ты мыслишь наиболее честно. Подключи его к ИИ, которым уже пользуешься, — в чате или терминале, чтобы он опирался на твои настоящие размышления, мудрость и цели. Только чтение, конфиденциально и лишь по твоему запросу.

## Два способа подключения

<CardGroup cols={2}>
  <Card title="В чате — без установки" icon="comments">
    Добавить Life Note то **Клод** или **ЧатГПТ** и зарегистрируйтесь один раз.
  </Card>
  <Card title="В терминале или агенте для программирования" icon="terminal">
    Инструмент командной строки `lifenote` для Claude Code, Cursor и Codex. Лучший для разработчиков.
  </Card>
</CardGroup>

## Подключить в Claude или ChatGPT

Нет необходимости в установке — вы просто добавляете разъем один раз.

<Steps>
  <Step title="В Claude (claude.ai)">
    Открой **Настройки → Коннекторы → Добавить свой коннектор**, вставь адрес ниже, затем нажми **Подключить** и войди в аккаунт Life Note.
  </Step>
  <Step title="В ChatGPT (Pro и выше)">
    Открой **Настройки → Коннекторы**, добавь свой коннектор с тем же адресом, затем войди.
  </Step>
</Steps>

Адрес коннектора Life Note:

```
https://mcp.mylifenote.ai/mcp
```

<Note>
  Для добавления своего коннектора может понадобиться платный план Claude или ChatGPT. Он также работает с Gemini Enterprise и другими помощниками с поддержкой MCP.
</Note>

<Note>
  **Только чтение и конфиденциальность.** Твой ИИ может *читать* дневник, мудрость, практики и цели. Он **не может** писать в дневник, менять настройки или получать доступ к чужим данным. Токен входа хранится безопасно, никогда в открытом виде. Отключить доступ можно в любой момент в настройках.
</Note>

## Разработчикам — CLI

Предпочитаете терминал или работу в агенте кодирования? Установите `lifenote` CLI для того же дневника в командной строке.

<Steps>
  <Step title="Установить и войти">
    Требуется Python 3.10+. [пипс](https://pipx.pypa.io/):

    ```bash
    pipx install lifenote
    lifenote auth login
    ```
  </Step>
  <Step title="Подключи к агенту для программирования">
    Claude Code — выполни эту команду. Cursor и Codex используют тот же подход; для Claude Desktop добавь её в настройки MCP.

    ```bash
    claude mcp add lifenote -- lifenote mcp
    ```
  </Step>
  <Step title="Научи агента выбирать подходящий момент">
    Установи встроенный навык, чтобы агент знал, когда обращаться к дневнику, а когда — нет:

    ```bash
    lifenote skills install
    ```
  </Step>
  <Step title="Или используй прямо из терминала">
    Ищи в дневнике и передавай результаты любому агенту:

    ```bash
    lifenote today
    lifenote search "anxiety about launch"
    lifenote search "burnout" --json | claude "summarize the patterns"
    ```
  </Step>
</Steps>

### Что может твой агент

14 инструментов только для чтения охватывают дневник, сохранённую мудрость, разговоры с наставниками, практики и квесты, жизненные ориентиры. Все сценарии выше работают и из терминала. Примеры для опытных пользователей:

> _Перекрестная ссылка на мой дневник и мою спасённую мудрость о выгорании — где они согласны, где они расходятся?_
>
> _Заполните мой последний месяц записей и напишите еженедельное резюме, которое я могу вставить в свой дневник._
>
> _«Учитывая мою цель в жизни и фокус в этом году, на что я действительно продвинулся — с доказательствами из моих записей?»_
