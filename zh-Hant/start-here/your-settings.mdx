## 手機上

點擊個人頭像，然後選擇 **設定**。

| 區塊 | 裡面有什麼 |
|---|---|
| **個人檔案** | 你的名字和照片。當 Life Note 找到你常寫到的人，這裡也會出現 **人物**。 |
| **導師** | 主要導師、預設日記回覆導師、導師模式、**告訴導師關於你的事**，以及 **管理已封鎖的導師**。 |
| **日記提醒與通知** | **管理通知** 會打開你的提醒，以及 Life Note 會寄給你的其他一切。 |
| **分享 Life Note** 與 **贈送 Life Note** | 你的推薦連結和已加入的朋友人數，還有送給別人的禮物。 |
| **支援** | **發送意見回饋** 會直接送到真人手上。 |
| **安全性** | 支援的手機上可使用 Face ID 或指紋解鎖。 |
| **外觀與語言** | 系統、淺色或深色、你的 **語言**，以及 **App 圖示**。 |
| **社群** | 我們的 Discord 和 Instagram。 |
| **條款** | 服務條款與隱私政策。 |
| **帳戶** | 帳單、**匯入與匯出**、**登出** 和 **帳戶管理**。 |

<Note>
  這個版面隨 Life Note 1.0.116 推出。如果你的設定看起來不一樣，請到 App Store 或 Google Play 更新 App。
</Note>

### 你的訂閱

如果你是在手機上訂閱，**帳單** 會顯示你的方案。**管理訂閱** 會帶你到 App Store 或 Google Play，在那裡變更或取消。如果你是月繳，帳單下方會出現 **改為年繳**。

### 匯入與匯出

匯入和匯出都在網頁版進行，那裡有足夠的空間處理檔案。手機上的 **匯入與匯出** 會給你網址：**複製連結**，或用 **傳到我的電腦** 從手機的分享選單傳給自己。詳見[匯入你的過去](/zh-Hant/start-here/bring-your-history-in)與[隱私與資安](/zh-Hant/start-here/privacy-and-security)。

### 登出

**登出** 現在會先問你一次，並顯示你之後可以用來登入的電子郵件。

## 選擇你的 App 圖示

前往 **設定 → 外觀與語言 → App 圖示**，從八款中挑一個。**夜晚** 是預設。其他是晨空、森林、午夜、黃昏、午睡、魔法書和經典。更換圖示時，手機可能會顯示一則簡短的確認。

## 網頁版

點擊側邊欄最下方你的名字，然後選擇 **設定**。同一個選單裡還有 **Guide**、**分享 Life Note**、**加入 Discord** 和 **登出**。

| 區塊 | 裡面有什麼 |
|---|---|
| **個人** | 你的照片和名字。 |
| **設定**（偏好設定） | 最上面是 **語言**，接著是主要導師、預設日記回覆導師、導師模式、關於你，以及已封鎖的導師。 |
| **通知** | 日記提醒、週日來信、導師問候，以及小提示與里程碑。詳見[日記提醒](/zh-Hant/advanced/reminders)。 |
| **分享 Life Note** | 你的推薦連結、已加入的朋友人數，以及 **贈送 Life Note**。 |
| **隱私** | **隱私鎖**：這台電腦專用的 PIN 碼。 |
| **主題** | 網頁版 Life Note 的外觀。 |
| **社群** | 我們的 Discord 和 Instagram。 |
| **帳單** | 你的方案、付款方式，以及取消或恢復訂閱。 |
| **數據管理** | **匯入**、**匯出**，以及 **將 Life Note 連接到你的 AI**。 |
| **帳戶管理** | 你的名字和電子郵件，以及 **刪除帳戶**。 |

每個區塊都有自己的網址，可以加入書籤。**mylifenote.ai/settings#notifications** 會直接打開通知。

### 鍵盤快捷鍵

在任何頁面、沒有在打字時按 **?**，或點擊設定區塊清單下方的 **鍵盤快捷鍵**，就能看到所有快捷鍵。**Ctrl + A**（Mac 上是 **⌘ + A**）會打開主題。
